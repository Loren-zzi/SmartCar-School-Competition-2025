# 2025 年智能车校赛代码

本仓库保存 **2025 年智能车校赛**的智能车程序，基于 **英飞凌 AURIX TC264** 和 **逐飞 TC264 开源库**开发，使用摄像头采集赛道图像，结合图像处理、舵机转向与双电机速度控制实现小车行驶。

适合用来学习摄像头智能车的程序结构、双核分工、赛道偏差计算和闭环控制。当前参数与比赛时的小车硬件和赛道相关，移植时需要重新调试。

## 主要内容

- **图像采集与处理**：MT9V03X 摄像头采集，包含二值化、边界搜索、中线与拐点处理等代码。
- **转向与差速**：根据图像偏差调整舵机输出和左右电机目标速度。
- **速度闭环**：编码器反馈与增量式 PID 电机控制。
- **双核协作**：CPU0 负责主控制逻辑，CPU1 负责图像采集、处理与 IPS200 显示。
- **赛道状态处理**：通过 `part` 等状态变量切换不同路段的控制参数。
- **辅助模块**：屏幕、按键、蜂鸣器，以及模糊 PID 相关源码；具体启用情况以主程序调用为准。

## 使用方法

1. 安装 AURIX Development Studio（ADS），准备与 TC264 工程匹配的编译和调试环境。
2. 在 ADS 中导入已有工程，选择本仓库根目录。工程内部名称保留为 `Seekfree_TC264_Opensource_Library`。
3. 参考 `推荐IO分配.txt`、`尽量不要使用的引脚.txt`，并以各模块源码中的实际引脚定义为准，核对接线。
4. 检查 TC264 主控、MT9V03X 摄像头、IPS200 屏幕、舵机、电机驱动及编码器配置。
5. 编译并下载，先检查摄像头图像、舵机中位、电机方向和编码器反馈，再低速上赛道调试。

编译产物和个人 IDE 工作区文件已通过 `.gitignore` 排除，首次使用需重新编译。原工程的修改名称说明和辅助脚本也保留在根目录，按需阅读后使用。

## 调参入口

| 文件 | 主要关注点 |
| --- | --- |
| `user/cpu0_main.c` | `base_speed`、`diff_factor`、`steering_gain` 及各 `part` 分支中的参数 |
| `code/PID.c` | 电机 PID 参数和输出限制 |
| `code/Servo.*` | 舵机中位、控制范围及 PWM 配置 |
| `code/Encoder.c` | 编码器方向和速度换算 |
| `code/image.c`、`car_control.c` | 图像处理、赛道中线和偏差计算 |
| `user/isr.c` | 5 ms 测速与电机控制、10 ms 按键和状态处理 |

建议按“图像正常 → 舵机方向和中位 → 电机方向与测速 → 速度闭环 → 低速循迹 → 路段参数”的顺序调试。不要直接套用原车速度、舵机范围和 PID 参数。
